# Жизненный цикл нормы

Триггер: история разработки, будущие изменения, спор о начале/окончании действия или переходных правилах. Обычная проверка редакции не требует исследования всей разработки.

1. Выбрать ветку: законопроект — [СОЗД](https://sozd.duma.gov.ru/); проект исполнительного органа — [regulation.gov.ru](https://regulation.gov.ru/); принятый акт — [официальное опубликование](https://publication.pravo.gov.ru/) и правовая система с редакциями. Не строить обязательную цепочку из всех порталов.
2. Идентифицировать проект по номеру, инициатору/разработчику, предмету и истории. Различать внесённый текст, редакции чтений, поправки, заключения и итоговый акт. «Разработка завершена», «архив» или принятие в чтении не означают действующее право.
3. Раздельно установить принятие, подписание, регистрацию при необходимости, опубликование и применимость. Сверять межсистемную ссылку по реквизитам и содержанию: сама ссылка может вести на другую инициативу. Не путать ID проекта, номер акта, регистрацию Минюста и номер публикации.
4. В итоговом тексте проверить основную дату вступления, исключения по пунктам, начало применения, переходные положения, обратное действие и срок действия. Сопоставить с датами фактов, последующими изменениями и отменой. Будущая редакция не заменяет действующую; запланированное окончание не исключает более раннюю отмену.
5. Вывод по каждому значимому положению: `норма/версия → событие и дата → временное правило → факты → применимость`. Отметить непроверенные звенья, не восполнять их догадкой.

Для PDF с пустым извлечением текста проверить изображение страниц. Сохранить происхождение, даты и объём прочтения; хэш идентифицирует файл, но не доказывает подпись. Даты API с часовым поясом не подменять календарной датой интерфейса без проверки смысла поля.

Сначала документация сервиса, затем известный реквизит и нужная версия. Новые адаптеры не требуются; действующий маршрут опубликования описан в [официальных источниках](official-sources.md). Нельзя объявлять просмотр карточки полным поиском или чтением всех вложений.
