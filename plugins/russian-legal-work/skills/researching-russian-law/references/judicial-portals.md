# Официальные судебные порталы

Триггер: работа с ВС, ГАС, московскими судами, КС либо судебным контролем решения ФАС. Маршрут РАС/КАД остаётся в `official-sources.md`.

Сначала официальная справка нужной формы. Проверить окончание запроса: изменились условия, завершилась загрузка, получен новый счётчик/сообщение. Старые строки под индикатором загрузки — не новая выдача. Начать с номера/УИД и суда; если пусто, проверить без лишних фильтров. Число актов, дел, обращений и заседаний различается.

| Источник | Маршрут и контроль |
| --- | --- |
| [ГАС и сайты судов](https://sudrf.ru/) | Выбрать суд, производство, инстанцию; искать по УИД либо номеру. Начальная страница может показывать только заседания дня. Карточка → движение → акты → связанные регистрации по УИД/прежнему номеру. Проверять отмену заочного решения тем же судом и повторное рассмотрение, а не только вышестоящие инстанции. Внутренние case_id не равны УИД |
| [ВС: дела и жалобы](https://www.vsrf.ru/lk/practice/claims) | Искать номер ВС либо номер первой инстанции; роль участника и связанные обращения сверять. Отказ в передаче может иметь продолжение. Тексты актов, дела/жалобы и списки слушаний — разные массивы; PDF → резолюция → дальнейшая история. Экономическая карточка может направлять в КАД |
| [Суды Москвы](https://mos-gorsud.ru/) | Различать Мосгорсуд и районный суд, судебное дело и материал; связать номер первой инстанции с жалобой. Живой сквозной поиск/выгрузка в обучении не подтверждены; актуальный интерфейс проверить по месту |
| [КС РФ](https://ksrf.ru/) | Различать постановление, определение и организационный документ. Читать предмет, резолюцию, обязательное толкование, временной эффект и последующее законодательное исполнение. Расширенная форма сквозным тестом не подтверждена |
| [ФАС](https://br.fas.gov.ru/) | Решение органа — не судебный акт. Разделить решение, предписание, процессуальное сообщение; связать по органу, дате, номеру, закупке/сторонам с судебным обжалованием. Частичная отмена не означает отмену всего акта. Исходный документ ФАС и судебное описание его содержания — разные источники |

В проверенной форме текстов ВС два добавленных фрагмента работали совместно («И»); альтернативные формулировки искать раздельно, не переносить семантику на другие формы. Узкий фильтр коллегии/производства может скрывать релевантный акт из-за метаданных.

При расхождении карточки и полного акта назвать оба источника и расхождение, проверить первичный текст и последующие акты. Не исправлять молча. Отсутствие текста, записи о жалобе или даты вступления не доказывает отсутствия события. Не называть всю историю проверенной по одному PDF.

При недоступности назвать фактическую ошибку; географическое ограничение — если подтверждено, иначе возможная причина. Не повторять одинаковые неудачные запросы. Резерв не снимает ограничений уверенности. Учебный успех одного суда не подтверждает все сайты и центральный банк.
