# Официальные и резервные источники

## Иерархия

1. Официальное опубликование нормы, сайт суда или органа, официальный реестр.
2. Признанная правовая система: КонсультантПлюс, ГАРАНТ, Кодекс.
3. Специализированная система: CaseLook, Casebook, СПАРК.
4. Открытый интегратор, включая Sudact.
5. Доктрина.
6. Обычный интернет только для обнаружения первоисточника.

Если официальный документ недоступен, указать источник копии, дату доступа и ограничение. Не превращать неподтверждённую копию в категоричный вывод. Ключевая позиция, проверенная только по агрегатору или вторичной копии, не может получать высокую уверенность.

В `research-evidence-log.md` различать поиск массива, открытие известного документа и проверку истории. Официальность не доказывает полноту поиска.

## Арбитражные суды

Использовать `ras.arbitr.ru` для тематического и полнотекстового поиска и официального PDF. Сужать выдачу редкой формулировкой, судом, периодом, участником, категорией и типом документа.

Для РАС фиксировать поисковую строку, суд, период, категорию, тип документа,
объем выдачи и число открытых PDF. Для КАД фиксировать номер дела, проверенные
инстанции, последнее процессуальное событие и недоступные документы.

Для ключевого акта:

1. открыть официальный PDF;
2. перейти по номеру в `kad.arbitr.ru`;
3. проверить стороны, роли, хронологию и все инстанции;
4. установить отмену, изменение, новое рассмотрение и итог;
5. сохранить ссылку на PDF и карточку дела.

RAS отвечает преимущественно за документ, КАД — за процессуальную историю. Одного сервиса недостаточно для полной проверки. Если технически не удалось открыть RAS или КАД, не писать, что официальная судьба дела проверена; перечислить, какие звенья хронологии остались неподтверждёнными.

## Верховный Суд и суды общей юрисдикции

Для ВС, ГАС, Москвы, КС или ФАС читать [порталы и историю](judicial-portals.md). Отказ в передаче не тождествен рассмотрению коллегией.

Sudact допустим для обнаружения, особенно по судам общей юрисдикции. Ключевой результат перепроверить официально. Если это невозможно, прямо указать ограничение.

Для Sudact фиксировать запрос, суд, период и отобранный документ. Не считать
агрегатор официальным подтверждением судьбы дела; отдельно записать результат
перепроверки на сайте суда или в ГАС «Правосудие».

## Нормативные акты и органы

Проверять официальный текст, дату опубликования, вступление в силу, применимую редакцию и переходные положения. Письмо органа использовать в пределах его компетенции и не приравнивать к нормативному акту.

В журнале указывать официальный портал, реквизиты, дату редакции, дату
вступления в силу и редакцию, применимую к фактам. Текущая редакция не заменяет
редакцию на юридически значимую дату.

## Официальное опубликование

`publication.pravo.gov.ru` — первичный источник факта опубликования, карточки
документа и официального PDF. API этого портала использовать только для
компактного отбора метаданных по реквизитам, периоду или иным известным данным:
в рабочих запросах указывать даты в формате `DD.MM.YYYY`. Отбор через API не
заменяет открытия карточки и PDF.

При обработке результата учитывать массив `DocumentTypes`; фильтр
`DocumentTypeId` может быть ненадёжным. Не делать юридически значимый вывод по
полю `DocumentText` без открытия карточки или официального PDF. После отбора
сверить реквизиты, дату опубликования и сам документ.

Этот маршрут подтверждает опубликование, но не определяет применимую редакцию,
вступление в силу, переходные положения или правовые связи: их проверять по
действующему исследовательскому маршруту. Если HTTPS-портал недоступен, не
переходить тихо на HTTP; зафиксировать техническое ограничение в журнале.
