# Контур.Фокус

Читать только для работы с Фокусом. Сначала [официальная справка](https://support.kontur.ru/focus) и [документы](https://focus.kontur.ru/site/docs), затем доступный модуль. Авторизованная главная страница не подтверждает доступ ко всем функциям.

1. Найти по ИНН/ОГРН, для конкретной регистрации ИП — ОГРНИП; название даёт кандидатов. Сверить идентификаторы, условия сделки, дату доступа и даты каждого значимого блока.
2. Прочитать сводку один раз, далее нужные события/разделы. Если блок уже достаточно проверен в Фокусе, не повторять весь сбор в СПАРК/Casebook. Адресная сверка первоисточника нужна для существенного факта, противоречия, устаревания либо получения документа/подписи.

| Блок | Проверка |
| --- | --- |
| Реквизиты и связи | Текущая/историческая запись, дата, основание прямой/косвенной связи. Общий адрес или телефон не доказывает контроль; риск связанного лица не переносится автоматически |
| Арбитраж/СОЮ | Роль → период → предмет/исход → дело → все значимые события → полный акт. Заявленное не равно взысканному; частичное прекращение не равно прекращению всего дела. ИИ-резюме — отбор. Судьба ключевого акта проверяется официально |
| ФССП | Текущее/историческое, точный должник, исполнительный документ, предмет и сумма. Исчезновение записи не доказывает оплату или прекращение |
| Банкротство | Намерение, заявление, процедура, сообщение и судебный акт различаются; смотреть последующие события и обжалование |
| Финансы/налоги | Дата среза, единицы, период, корректировки, отдельная/консолидированная отчётность. Несовпадающие начало/конец не склеивать; аудит читать с оговорками. Ноль не равен отсутствию данных |
| Закупки/контроль | Роль участника и актуальность статуса; событие не равно нарушению. Существенное сверить с ЕИС/ЕРКНМ и документами |
| Активы/права/статус | Залоги — роль и конкретный предмет; знаки — заявка/регистрация/упоминание; лицензия — действие и дата; СРО — статус компании, не только объединения |
| Раскрытие | Дата события/публикации, исправляющее сообщение, первичный документ |

Индекс, экспертный рейтинг, экспресс-отчёт и Скоринг не являются юридическим заключением. Читать методику показателя и период; соотносить с конкретной сделкой. Публичный санкционный маркер не подтверждает полный доступ к Комплаенсу или актуальный официальный скрининг.

Экспорт: выбрать нужные разделы/формат, проверить актуальные лимиты и фактические строки полученного файла против фильтров/счётчиков. Архивная строка или кнопка не равна скачанному и проверенному файлу. При неработающем PDF использовать уже показанную ссылку в той же разрешённой сессии; адреса не угадывать.

Без поручения не подключать пробный период, мониторинг, общие списки, платные/квотируемые отчёты, загрузку клиентских документов или изменение аккаунта. Веб-доступ не даёт API-доступа.

Границы обучения: базовые карточки и документы проверялись; качество ИИ-анализа, действующая модель Скоринга, полный Комплаенс, доставка уведомлений и полнота локального экспорта не подтверждены. Отчёт системы по недвижимости не считать выпиской ЕГРН. Сохранять только краткую доказательственную запись, не закрытые тексты и персональную историю аккаунта.
