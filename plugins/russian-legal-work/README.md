# Russian Legal Work

Версия **0.5.0**. Четыре навыка для исследования российского права, проверки контрагентов и подготовки юридических документов в Codex.

## Состав пакета

| Навык | Назначение |
| --- | --- |
| `researching-russian-law` | Поиск и проверка законодательства, судебной практики и правовых позиций |
| `checking-russian-counterparties` | Проверка российских юридических лиц и ИП, оценка рисков и рекомендации по работе с контрагентом |
| `drafting-russian-procedural-documents` | Подготовка процессуальных документов и внесудебных обращений в органы власти |
| `writing-russian-legal-opinions` | Подготовка правовых заключений, меморандумов и юридических справок |

## Совместная работа навыков

Нужный навык выбирается по задаче. Для подготовки заключения, иска или отзыва может потребоваться исследование законодательства и судебной практики. В этом случае подготовка документа включает необходимое исследование.

Готовые и актуальные результаты используются повторно. Если не хватает отдельных сведений, исследование дополняется только в необходимой части. Пользователю не нужно заранее составлять отдельный исследовательский пакет.

Подробные инструкции по отдельным системам и специальным вопросам читаются по необходимости. Результаты исследования отделяются от предположений и неподтверждённых сведений.

## Доступ к источникам

Пакет не включает аккаунты, подписки, API или коннекторы коммерческих систем. Пользователь самостоятельно авторизуется в необходимых сервисах. Если приоритетный источник недоступен, навык сообщает об этом и согласует дальнейший порядок работы.

Возможности управления браузером и отдельными приложениями, создания файлов и проверки электронных подписей зависят от среды пользователя. Работа с отдельным приложением КонсультантПлюс описана в инструкциях, но пока не проверена на практике.

## Установка

1. Скачайте и распакуйте весь репозиторий, сохранив структуру папок.
2. В терминале выполните команды ниже. В первой команде замените путь на полный путь к распакованной папке репозитория — той, где находятся `.agents` и `plugins`.

```bash
codex plugin marketplace add /absolute/path/to/russian-legal-work-main
codex plugin add russian-legal-work@russian-legal-work
```

3. После установки откройте новую задачу Codex.

## Структура

```text
.codex-plugin/plugin.json
skills/
  researching-russian-law/
  checking-russian-counterparties/
  drafting-russian-procedural-documents/
  writing-russian-legal-opinions/
```

В папках навыков находятся основные инструкции, дополнительные материалы и шаблоны документов.

## Перед использованием результата

Проверьте факты, актуальность источников, полноту доказательств и итоговые выводы. Перед подачей процессуального документа дополнительно проверьте его реквизиты, приложения и соблюдение требований к подаче.

Пакет помогает организовать работу, но не заменяет решение юриста.
